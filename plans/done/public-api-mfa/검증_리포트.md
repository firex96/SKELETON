## 3. 브라우저 육안 확인

`local` 프로필로 8081 에 기동(`MFA_SECRET_ENCRYPTION_KEY` 는 이 확인에만 쓰려고 새로 만든 값)했다. 회원가입·로그인 API 로 테스트 사용자를 만들고, `/user/mfa/totp/setup`·`activate` 로 TOTP 를 켰다(시크릿으로 코드를 계산, 복구 코드 10개 수신). 관리자 API 로 3rd-party 클라이언트를 만든 뒤 Chrome 으로 따라갔다.

1. `GET /oauth2/authorize?…&state=visual-mfa` → 로그인 화면(`/oauth2/login`)
2. 로그인 → **2단계 화면(`/auth/mfa`)** — 코드 입력란, 「복구 코드로 인증」 펼침
3. 계산한 TOTP 코드 제출 → 기다리던 authorize → 동의 화면: 클라이언트 「육안확인 2차인증 서드파티 앱」, scope `openid`·`profile`
4. 동의 → `http://localhost:8080/callback?code=…&state=visual-mfa`(받는 서버가 없어 브라우저 오류 화면 — 예상 동작)

- 로컬 DB 에 육안 확인용 사용자 `visual_mfa_6c086e` 와 클라이언트 「육안확인 2차인증 서드파티 앱」이 남아 있다(docker compose 로컬 DB 전용).
